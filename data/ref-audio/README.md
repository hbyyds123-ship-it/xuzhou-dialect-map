# data/ref-audio/ — 范本音放这里

范本音 = 请发音人照词条念一遍的录音，学习侧（听音选词）优先播它，
替代浏览器里那个普通话合成音。

## 怎么加

1. 把录音拷进这个目录（可以建子目录，如 `2026-11/`）；
2. 在这一层跑 `npm run refs`，它会扫目录、按文件名对词条、重写 `data/refs.js`；
3. 对不上的文件名它会列出来，改个名再跑一次即可。

文件名认三种写法：

| 文件名 | 认得的依据 |
|---|---|
| `maozi.mp3` | 词条 id |
| `茅子.mp3` | 词本身 |
| `01-茅子.mp3`、`01_maozi.wav` | 前面带序号，会自动剥掉 |

支持 mp3 / wav / m4a / aac / ogg / webm / flac。单条建议 30 秒内、16kHz 以上。

## 两条注意

- **这里只放"给定方言"的范本**。用户自己家录的说法不在这里，那是浏览器里的事，
  拖进词条册就行，不上传、不进仓库。
- 录音要**事先取得发音人同意**，并在 `data/refs.js` 生成后把发音人写进你的发布说明里。
  别把别人的声音当成"素材"随便发。
